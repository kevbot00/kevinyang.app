# kevinyang.app

Personal site for Kevin Yang. Plain HTML, CSS, and a little JavaScript, with no build step.

## Run locally

```bash
python3 -m http.server 4321
```

Then open http://localhost:4321.

## Deploy

Hosted on Cloudflare Pages from this repo. Build command is empty and the output directory is the repo root. Every push to `main` redeploys.
