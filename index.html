Selected work

OTTO Sport AI · 2021 – 2026 · Technical owner

League scheduling engine

The engine that builds season schedules for youth sports leagues, running on a platform of 50+ independently deployed microservices. I led its architecture and coordinated 2 to 3 engineers on matchup generation, cutting manual schedule creation time by up to 75%.

  1. Constraints

    Built the conflict engine that fits games into open slots using per-grouping rules for games per team, dates, time windows, locations, game length, and coach conflicts.

  2. Speed

    Rebuilt conflict checks on 5 minute slots, taking generation from 30+ seconds to about 5 on 1,000+ game stress tests.

  3. Extensibility

    Designed matchup generation around the Strategy pattern so new league formats needed no scheduler changes.

  4. Migration

    Rebuilt legacy V1 scheduling features in V3, helping move the last 3 large clients off V1.
